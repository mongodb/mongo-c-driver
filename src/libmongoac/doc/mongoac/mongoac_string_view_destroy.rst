mongoac_string_view_destroy
===========================

Synopsis
--------

.. code-block:: c

   #include <mongoac/string.h>

   void mongoac_string_view_destroy(mongoac_string_view_t sv);

Description
-----------

Does nothing.

This function exists only to force cbindgen to declare ``mongoac_string_view_t`` in the crate header.
